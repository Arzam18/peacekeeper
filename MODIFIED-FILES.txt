The current `Arzam18/peacekeeper` fork network `src/default.nn` was confirmed in commit `883249d17e0ec5b3d0f8efa77e9a8fec3d7eab05`. It is 18,883,588 bytes and has SHA-256 `4e65641f0a32034822d514f959a7ac101cc70491fb4dfdd4a8368a9c6e7524d8`. The old pin (`13cc994d...`) referred to a different network revision and is replaced with this exact fork network identity.

The build remains strict: it checks both size and SHA-256 and will fail on any different model. The build metadata also records the checked-out Git remote and commit. No network file is included or overwritten by this patch.
